Which one?

I just want the best build.

Take v17. It has the newest engine and every fix listed above.

I play on PC.

Use v17 or v15. v13 does not support PCVR.

My mod misbehaves on v17.

Try v15. Custom shaders can be toggled in the quick menu or post-processing menu if a mod breaks under strict GLES rules.

The game runs too slowly.

Try v13 if your mod supports LZDoom, and read the performance settings page.

Performance tips

Biggest single change

Switch to OpenGL Lite

Set vid_preferbackend = 2 to use the OpenGL ES renderer, called OpenGL Lite in the menus. It is built for weaker GPUs and headset hardware, with lighter GPU work, 8-bit textures and a simpler rendering path. vid_preferbackend = 0 is the older desktop-style OpenGL path. It is usually slower on mobile hardware, so keep it for desktop testing or compatibility.

SettingTryWhy
Render the skydomeOffSwaps in a cheap coloured sky and cuts GPU cost.
ReflectionsOffExpensive, and one of the first things to turn off on mobile VR.
Light shadowmapsOffGenerating them is costly and rarely worth it in a headset.
Dynamic lightsDisabledOne of the heaviest costs in VR. Keep them off on standalone unless you are tuning for one scene.
Sprite Cull Distanceabout 2000Farther sprites add GPU work. Lower it in busy scenes.
Wall Cull Distanceabout 3000Helps in large maps and open areas.
Post-processingOff or lowEvery extra fullscreen pass runs twice, once per eye.
Refresh Rate72 or 90 HzStart at your headset's stable rate and lower it if the scene stutters.

If culling makes things pop in, turn on Global fade to hide it. For the full list of settings, see the performance settings wiki page.

Suggested order

  1. Switch to vid_preferbackend = 2.
  2. Turn off the skydome and reflections.
  3. Turn off light shadowmaps and reduce dynamic light counts.
  4. Lower the sprite and wall cull distances.
  5. Reduce post-processing, then adjust the refresh rate.
